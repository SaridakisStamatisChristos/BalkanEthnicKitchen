# Balkan Cookbook — 600-Recipe Archive

An original **Balkan-inspired cookbook** of **600 recipes** across **12 country collections**, with individual Markdown recipes and complete printable editions.

**Read the full cookbook:** [Complete PDF](exports/balkan-cookbook-printable.pdf) · [Printable HTML](exports/balkan-cookbook-printable.html) · [Original table of contents](cookbook/TABLE-OF-CONTENTS.md) · [Cover artwork](exports/cover.png)

> **Scope and provenance:** These are original writeups inspired by regional home cooking, mixing recognizable traditional dishes and creative regional-style variants. The collection is not an independently certified guide to culinary authenticity. The broad regional scope includes Slovenia, Romania, Kosovo and Turkey.
